## 平台范围

仓库 CI 配置 Windows、macOS、Linux 三个平台。只有对应 CI 运行成功后才能认定该平台通过本次自动测试；CI 通过不等于 WorkBuddy、TRAE 等客户端已完成真实交互验收。

本项目目前没有宣称所有 Agent 均已验证兼容。客户端验收还应包含上传附件、安装技能、显示进度、展示图纸以及指定档位重跑。
