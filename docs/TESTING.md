## 如何复现

```bash
node scripts/bead.cjs setup
node scripts/bead.cjs doctor
npm test
```

测试包含：

- CIEDE2000 标准色差参考值、41 色原序、透明阈值和精确统计。
- 六档从原图独立转换，长图、竖图、白色、透明图、手机方向与损坏文件。
- PNG/PDF/CSV/JSON 导出、500×500 图纸、v1 工程重导、单档故障后重跑。
- 后台任务完成事件、提前可用文件、取消、进程中断、打包失败与状态恢复。
- Windows PowerShell 5.1/7、npm.cmd 包装器、中文及特殊字符路径、文件锁恢复。

Windows 专属用例在 macOS/Linux 上跳过。Windows 的托管 npm 测试需要网络，安装依赖的全新缓存位于临时目录；其他转换测试在依赖就绪后离线执行。
